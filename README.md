# monthly-report（月度工作汇报表生成）

这是一个 Codex 技能（skill），用来自动汇总每周的周报 Excel，生成符合固定模板的月度工作汇报表。

## 它做什么

1. 读取指定月份目录下的所有周报文件（如 `20261010周报文件.xlsx`）。
2. 提取"本周工作 / 完成效果"与"下周工作安排"，跨周去重、合并递进条目。
3. 把内容写入月度模板的固定表格（只写值，不改模板任何样式）。
4. 输出 `月度工作汇报YYYYMM.xlsx`，例如 `月度工作汇报202610.xlsx`。

## 仓库结构

```
├── SKILL.md                  # 技能说明（Codex 读取的入口文档）
├── scripts/fill_monthly.py   # 核心脚本：复制模板、汇总周报、写入数据
├── references/fill-rules.md  # 填写规则细则（日期、合并、格式、核对清单）
├── assets/月度工作汇报表模板.xlsx   # 只读的内置模板
└── agents/openai.yaml        # Codex 技能界面配置
```

## 使用方式

作为 Codex 技能：把本仓库放到 `~/.codex/skills/monthly-report`，然后对 Codex 说
"用 monthly-report 把 D:/桌面/桌面文件/周报 里的周报汇总成月度工作汇报表"。

直接运行脚本：

```bash
python scripts/fill_monthly.py --month 2026-10 --weeks "D:/桌面/桌面文件/周报" --force
```

条目数超过模板预留行数时脚本会报错退出，此时需要把同类条目合并后通过
`--work-items` / `--plan-items` 传入 JSON（格式 `[[文字, 完成效果], ...]`），
或显式加 `--insert-rows` 允许加行（不推荐）。

## 核心约束

- **模板只读**：两个模板文件（用户目录的和内置的）永远不会被修改，所有写入只发生在新生成的输出文件上。
- **结构固定**：上月工作 14 行、下月计划 6 行；除两个日期字段（汇报日期、汇报时间段）和数据区单元格外，与模板逐项一致（合并区 87 处、总行数 27 行均完全相同）。
- **汇报日期**：取当月最后一个工作日（与模板自带示例一致）。
- **行高自适应**：数据行行高按文字行数显式计算写入，避免 Excel 自适应导致的行距过大。
- **生成后核对**：每次生成都会对比模板，确认除日期与数据外零差异。
